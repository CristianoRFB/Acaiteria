# Estrutura de leads

Não há leads confirmados. A Açaí + Sabor é o tenant/cliente original, não um lead. Quando uma oportunidade real for confirmada, crie `leads/<slug>/` com `LEAD_CONTEXT.md`, `LEAD_REFERENCE_SUMMARY.md`, `LEAD_VISUAL_DIRECTION.md` e as pastas `assets/`, `captures/` e `generated/`; depois atualize os manifestos e rode `npm run docs:leads`.
